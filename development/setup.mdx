## Initial Setup

<Steps>
  <Step title="Clone the Repository">
    Clone the ProyectoWeb repository to your local machine:
    
    ```bash
    git clone <repository-url>
    cd ProyectoWeb
    ```
  </Step>

  <Step title="Install Dependencies">
    Install all required project dependencies:
    
    <CodeGroup>
      ```bash npm
      npm install
      ```

      ```bash yarn
      yarn install
      ```

      ```bash pnpm
      pnpm install
      ```
    </CodeGroup>
  </Step>

  <Step title="Environment Configuration">
    Create a `.env.local` file in the root directory with your environment variables:
    
    ```bash
    cp .env.example .env.local
    ```
    
    <Warning>
      Never commit `.env.local` or any files containing sensitive credentials to version control.
    </Warning>
    
    Configure the following essential variables:
    
    ```bash .env.local
    # Application Settings
    NODE_ENV=development
    PORT=3000
    
    # Database Configuration
    DATABASE_URL=postgresql://user:password@localhost:5432/proyectoweb
    
    # API Keys (if applicable)
    API_KEY=your_api_key_here
    
    # Frontend URL
    NEXT_PUBLIC_APP_URL=http://localhost:3000
    ```
  </Step>

  <Step title="Database Setup">
    If your project uses a database, set it up and run migrations:
    
    ```bash
    # Create database
    npm run db:create
    
    # Run migrations
    npm run db:migrate
    
    # Seed initial data (optional)
    npm run db:seed
    ```
  </Step>

  <Step title="Start Development Server">
    Launch the development server:
    
    <CodeGroup>
      ```bash npm
      npm run dev
      ```

      ```bash yarn
      yarn dev
      ```

      ```bash pnpm
      pnpm dev
      ```
    </CodeGroup>
    
    <Tip>
      The development server typically runs on `http://localhost:3000` with hot-reload enabled.
    </Tip>
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Port Already in Use">
    If port 3000 is already in use:
    
    ```bash
    # Find and kill the process
    lsof -ti:3000 | xargs kill -9
    
    # Or use a different port
    PORT=3001 npm run dev
    ```
  </Accordion>

  <Accordion title="Node Modules Issues">
    If you encounter dependency issues:
    
    ```bash
    # Remove node_modules and lock file
    rm -rf node_modules package-lock.json
    
    # Clear npm cache
    npm cache clean --force
    
    # Reinstall
    npm install
    ```
  </Accordion>

  <Accordion title="Environment Variables Not Loading">
    Ensure:
    - File is named `.env.local` (not `.env.local.txt`)
    - File is in the project root directory
    - Restart the development server after changes
    - Variables are prefixed with `NEXT_PUBLIC_` for client-side access (if using Next.js)
  </Accordion>

  <Accordion title="Database Connection Errors">
    Verify:
    - Database service is running
    - Connection string format is correct
    - Database exists and is accessible
    - User has proper permissions
    
    ```bash
    # Test database connection
    npm run db:test
    ```
  </Accordion>
</AccordionGroup>
