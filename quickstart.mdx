## Accessing the Project

<Steps>
  <Step title="Clone the Repository">
    Get a local copy of the ProyectoWeb repository:

    ```bash
    git clone https://github.com/SalomonAvila/ProyectoWeb.git
    cd ProyectoWeb
    ```
  </Step>

  <Step title="Review the Structure">
    The current repository structure:

    ```
    ProyectoWeb/
    ├── Documentos/
    │   ├── Proyecto desarrollo web 2026-10.pdf  (Main specification)
    │   └── HOLA ESTA ES UNA PRUEBA.txt          (Test file)
    ├── README.md                                 (Basic readme)
    └── .git/                                     (Git repository)
    ```
  </Step>

  <Step title="Read the Specification">
    The main project specification is located at:
    
    ```
    Documentos/Proyecto desarrollo web 2026-10.pdf
    ```

    This 9-page document contains:
    - Project requirements
    - Technical specifications
    - Development roadmap
    - Architecture plans

    <Tip>
      Start by reviewing this PDF to understand the project vision and requirements.
    </Tip>
  </Step>

  <Step title="Explore the Documentation">
    Navigate through this documentation site to learn about:
    - Project overview and goals
    - Planned architecture
    - Development guidelines
    - Best practices and standards
  </Step>
</Steps>
