## Getting Started

<Steps>
  <Step title="Clone the Repository">
    Clone the ProyectoWeb repository to your local machine:

    ```bash
    git clone https://github.com/SalomonAvila/ProyectoWeb.git
    cd ProyectoWeb
    ```
  </Step>

  <Step title="Install Dependencies">
    Install the required dependencies using your preferred package manager:

    <CodeGroup>
    ```bash npm
    npm install
    ```

    ```bash yarn
    yarn install
    ```

    ```bash pnpm
    pnpm install
    ```
    </CodeGroup>
  </Step>

  <Step title="Configure Environment">
    Create a `.env.local` file in the root directory and add your configuration:

    ```bash .env.local
    # Application Configuration
    NODE_ENV=development
    PORT=3000

    # Database Configuration (if applicable)
    DATABASE_URL=your_database_url_here

    # API Keys (if applicable)
    API_KEY=your_api_key_here
    ```

    <Warning>
      Never commit `.env.local` or any file containing sensitive credentials to version control.
    </Warning>
  </Step>

  <Step title="Start the Development Server">
    Run the development server:

    <CodeGroup>
    ```bash npm
    npm run dev
    ```

    ```bash yarn
    yarn dev
    ```

    ```bash pnpm
    pnpm dev
    ```
    </CodeGroup>

    The application will be available at `http://localhost:3000`
  </Step>

  <Step title="Verify Installation">
    Open your browser and navigate to `http://localhost:3000` to verify the installation was successful.

    <Tip>
      If you encounter any issues, check the [Troubleshooting](#troubleshooting) section below.
    </Tip>
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Port already in use" icon="plug">
    If port 3000 is already in use, you can specify a different port:

    ```bash
    PORT=3001 npm run dev
    ```
  </Accordion>

  <Accordion title="Module not found errors" icon="exclamation-triangle">
    If you encounter module errors, try:

    ```bash
    # Delete node_modules and reinstall
    rm -rf node_modules package-lock.json
    npm install
    ```
  </Accordion>

  <Accordion title="Environment variables not loading" icon="gear">
    Ensure your `.env.local` file is in the root directory and properly formatted. Restart the development server after making changes.
  </Accordion>
</AccordionGroup>
